# Сборка CW Keyer на макетке (Breadboard + Arduino Uno / Nano)
> Профессиональная настольная версия v1.7.1: OLED 0.96" SSD1306 + 3 потенциометра (WPM 10..60 + Pitch 400..1200 Гц + Volume) + Двухрычажный ямбический манипулятор (Режим B) / Однорычажное весло + NPN усилитель BC547 + Светодиод KEY (D8)

---

## 1. Общая карта подключений к Arduino Uno / Nano

```
                           Arduino Uno / Nano
                       ┌────────────────────────┐
                       │          VIN / +5V (*) ├─── [Красная шина питания + макетки]
                       │                    GND ├─── [Синяя шина земли GND]
                       │                        │
  ВЕСЛО (ТОЧКИ, DIT)   │                     D2 ├─── TIP (3.5 мм)  [Указательный палец]
  ВЕСЛО (ТИРЕ, DAH)    │                     D3 ├─── RING (3.5 мм) [Большой палец]
  ЗВУК (PWM)           │                     D6 ├─── [1 кОм] ──► База (B) BC547
  СВЕТОДИОД KEY (Красн)│                     D8 ├─── [1 кОм] ──► Анод (+) Красного LED
                       │                        │
  СКОРОСТЬ (WPM 10-60) │                     A0 ├─── Средний вывод POT 1 (10 кОм)
  ТОН (PITCH 400-1200) │                     A2 ├─── Средний вывод POT 2 (10 кОм)
                       │                        │
  OLED ДИСПЛЕЙ (SDA)   │               A4 (SDA) ├─── SDA дисплея SSD1306 (Fast I2C)
  OLED ДИСПЛЕЙ (SCL)   │               A5 (SCL) ├─── SCL дисплея SSD1306 (Fast I2C)
                       └────────────────────────┘

(*) ВАЖНОЕ ЗАМЕЧАНИЕ ПО ПИТАНИЮ КЛОНОВ NANO:
При питании платы от USB на пине "5V" у многих клонов напряжение отсутствует.
Красную шину питания макетки подключайте к контакту "VIN" (на нем присутствуют ~4.2 В от USB).
```

---

## 2. Пошаговые схемы узлов

### Блок А. Подключение весла (Гнездо 3.5 мм TRS)
* **SLEEVE (Резьба / корпус гнезда)** ➔ в синюю шину **GND**.
* **TIP (Кончик)** ➔ в пин **`D2`** Arduino. *(Точки, указательный палец / правый контакт)*
* **RING (Кольцо)** ➔ в пин **`D3`** Arduino. *(Тире, большой палец / левый контакт)*
*(В скетче включены встроенные подтяжки `pinMode(..., INPUT_PULLUP)` — внешние резисторы 10 кОм не обязательны).*

---

### Блок Б. Звуковой тракт (BC547 + Динамик + Плавный регулятор громкости)

```text
                     +Питание (+5V / VIN)
                              │
                    ┌─────────┴─────────┐
                    │                   │
             [POT 3: ГРОМКОСТЬ 1 кОм]   │
             1 (крайняя)  2 (центр)     │
                    │         │         │
                    └─[68 Ом]─┘         │  ◄── ВАЖНО: Резистор 47..100 Ом параллельно 
                              │                ножкам 1 и 2 дает плавный ход по всей шкале!
             [Красный (+) провод динамика]
                              │
             [Черный (-) провод динамика]
                              │
                              ├──────────────────────┐
                              │                      │
                       Коллектор (C) BC547        [Конденсатор 100 нФ]
                              │                      │
      Arduino D6 ── [1 кОм] ── База (B)              │ (срезает колючие гармоники ШИМ)
                              │                      │
                         Эмиттер (E) ────────────────┴──── GND (Шина земли)
```

> **Цоколевка транзистора BC547 (плоской стороной с надписью к себе, ножками вниз):**
> * Ножка 1 (слева): **Коллектор (C)** ➔ к черному проводу динамика и конденсатору 100 нФ
> * Ножка 2 (центр): **База (B)** ➔ через резистор 1 кОм в пин `D6` Arduino
> * Ножка 3 (справа): **Эмиттер (E)** ➔ в синюю шину `GND`

---

### Блок В. Подключение светодиода передачи (Индикация KEY)

* **КРАСНЫЙ СВЕТОДИОД (вспыхивает в такт точкам и тире):**
  * **Длинная ножка (Анод, +)** ➔ через резистор **1 кОм** (или 220–470 Ом) в пин **`D8`** Arduino.
  * **Короткая ножка (Катод, -)** ➔ в синюю шину **`GND`**.

---

### Блок Г. Подключение трёх потенциометров

1. **POT 1: Регулировка скорости (WPM 10–60) — 10 кОм (B10K):**
   * Левая ножка ➔ в шину **GND**
   * Средняя ножка (ползунок) ➔ в пин **`A0`** Arduino
   * Правая ножка ➔ в шину **+5V / VIN**

2. **POT 2: Регулировка тона звука (PITCH 400–1200 Гц) — 10 кОм (B10K):**
   * Левая ножка ➔ в шину **GND**
   * Средняя ножка (ползунок) ➔ в пин **`A2`** Arduino
   * Правая ножка ➔ в шину **+5V / VIN**

3. **POT 3: Регулировка громкости (VOLUME) — 1 кОм (B1K):**
   * Левая ножка (1) ➔ в шину **+5V / VIN**
   * Средняя ножка (2) ➔ к красному (+) проводу динамика
   * Параллельно ножкам 1 и 2 ➔ впаян/вставлен резистор **47–100 Ом**
   * Правая ножка (3) ➔ свободна

---

### Блок Д. Подключение OLED дисплея 0.96" I2C (SSD1306 128x64)
* **GND** ➔ в синюю шину **GND**
* **VCC** ➔ в красную шину **+5V / VIN**
* **SCL** ➔ в пин **`A5`** Arduino Nano (тактовая линия Fast I2C 400 кГц)
* **SDA** ➔ в пин **`A4`** Arduino Nano (линия данных Fast I2C 400 кГц)

---

## 3. Таблица быстрой сверки проводки (Pin-to-Pin)

| Откуда | Куда | Назначение узла |
|---|---|---|
| Arduino `VIN` | Красная шина макетки (+) | Питание схемы (~4.2 В от USB) |
| Arduino `GND` | Синяя шина макетки (-) | Общий минус схемы |
| Arduino `D2` | Гнездо 3.5 мм (TIP) | Контакт точек (указательный палец) |
| Arduino `D3` | Гнездо 3.5 мм (RING) | Контакт тире (большой палец) |
| Гнездо 3.5 мм (SLEEVE) | Синяя шина макетки (-) | Земля манипулятора |
| Arduino `D6` | Резистор 1 кОм ➔ База BC547 | Сигнал генерации звука |
| Эмиттер BC547 | Синяя шина макетки (-) | Земля каскада УНЧ |
| Коллектор BC547 | Черный провод динамика + 100 нФ | Выход усилителя |
| Другой вывод 100 нФ | Синяя шина макетки (-) | Сглаживание гармоник |
| Красный провод динамика | Средний вывод POT 3 (Громкость) | Питание динамика |
| Крайний вывод POT 3 | Красная шина макетки (+) | Питание регулятора громкости |
| Arduino `D8` | Резистор 1 кОм ➔ Анод LED | Светодиод KEY |
| Катод LED | Синяя шина макетки (-) | Земля светодиода |
| Arduino `A0` | Средний вывод POT 1 (Скорость) | АЦП WPM (10..60 WPM) |
| Arduino `A2` | Средний вывод POT 2 (Тон) | АЦП PITCH (400..1200 Гц) |
| Arduino `A4` | Пин SDA дисплея OLED | Данные I2C |
| Arduino `A5` | Пин SCL дисплея OLED | Тактирование I2C |
