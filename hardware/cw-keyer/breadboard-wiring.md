# Сборка CW Keyer на макетке (Breadboard + Arduino Uno / Nano)
> Максимальная настольная версия: OLED 0.96" + 3 потенциометра (2x 10кОм для WPM и Тона + 1кОм для Громкости) + Весло СРТ + NPN усилитель + Светодиоды PWR и KEY

---

## 1. Общая карта подключений к Arduino Uno / Nano

```
                           Arduino Uno / Nano
                       ┌────────────────────────┐
                       │                    +5V ├─── [Красная шина питания +5V]
                       │                    GND ├─── [Синяя шина земли GND]
                       │                        │
  ВЕСЛО (ТОЧКИ, DIT)   │                     D2 ├─── TIP (3.5 мм)  [+ 10кОм к +5V]
  ВЕСЛО (ТИРЕ, DAH)    │                     D3 ├─── RING (3.5 мм) [+ 10кОм к +5V]
  ЗВУК (PWM)           │                     D6 ├─── [1 кОм] ──► База (B) BC547
  СВЕТОДИОД KEY (Красн)│                     D8 ├─── [1 кОм] ──► Анод (+) Красного LED
                       │                        │
  СКОРОСТЬ (WPM)       │                     A0 ├─── Средний вывод POT 1 (10 кОм)
  ТОН ЗВУКА (PITCH)    │                     A2 ├─── Средний вывод POT 2 (10 кОм)
                       │                        │
  OLED ДИСПЛЕЙ (SDA)   │               A4 (SDA) ├─── SDA дисплея SSD1306
  OLED ДИСПЛЕЙ (SCL)   │               A5 (SCL) ├─── SCL дисплея SSD1306
                       └────────────────────────┘
```

---

## 2. Пошаговые схемы узлов

### Блок А. Подключение весла (Гнездо 3.5 мм TRS косичкой МГТФ)
* **SLEEVE (Земля / резьба с гайкой)** ➔ в синюю шину **GND**.
* **TIP (Кончик)** ➔ в пин **`D2`** Arduino + резистор **10 кОм** на шину **+5V**. *(Точки, указательный палец)*
* **RING (Кольцо)** ➔ в пин **`D3`** Arduino + резистор **10 кОм** на шину **+5V**. *(Тире, большой палец)*

---

### Блок Б. Звуковой тракт (BC547B + Динамик + Регулятор громкости на 1 кОм)

```text
                      +5V (Шина питания)
                       │
             ┌─────────┴─────────┐
             │                   │
      [POT 3: ГРОМКОСТЬ 1 кОм]   │
     1 (крайняя)  2 (центр)      │
     [ +5V ] ───► [Красный (+) провод динамика]
                         │
                 [Черный (-) провод динамика]
                         │
                         ├──────────────────────┐
                         │                      │
                  Коллектор (C) BC547        [Конденсатор 100 нФ]
                         │                      │
 Arduino D6 ── [1 кОм] ── База (B)              │ (фильтр мягкого синуса)
                         │                      │
                    Эмиттер (E) ────────────────┴──── GND (Шина земли)
```

> **Цоколевка транзистора BC547 (плоской стороной к себе, ножками вниз):**
> * Ножка 1 (слева): **Коллектор (C)** ➔ к черному проводу динамика и конденсатору
> * Ножка 2 (центр): **База (B)** ➔ через резистор 1 кОм в пин `D6`
> * Ножка 3 (справа): **Эмиттер (E)** ➔ в шину GND

---

### Блок В. Подключение светодиодов (Индикация)

1. **ЗЕЛЕНЫЙ СВЕТОДИОД (Питание PWR — горит всегда при включении):**
   * **Длинная ножка (Анод, +)** ➔ через резистор **1 кОм** к красной шине **`+5V`**.
   * **Короткая ножка (Катод, -)** ➔ в синюю шину **`GND`**.

2. **КРАСНЫЙ СВЕТОДИОД (Передача KEY — вспыхивает в такт точкам и тире):**
   * **Длинная ножка (Анод, +)** ➔ через резистор **1 кОм** (или 220 Ом) в пин **`D8`** Arduino.
   * **Короткая ножка (Катод, -)** ➔ в синюю шину **`GND`**.

---

### Блок Г. Подключение трёх потенциометров (Точные номиналы)

1. **POT 1: Регулировка скорости (WPM 10–45) — 10 кОм (B10K):**
   * Левая ножка ➔ в шину **GND**
   * Средняя ножка (ползунок) ➔ в пин **`A0`** Arduino
   * Правая ножка ➔ в шину **+5V**

2. **POT 2: Регулировка тона звука (PITCH 450–850 Гц) — 10 кОм (B10K):**
   * Левая ножка ➔ в шину **GND**
   * Средняя ножка (ползунок) ➔ в пин **`A2`** Arduino
   * Правая ножка ➔ в шину **+5V**

3. **POT 3: Регулировка громкости (VOLUME) — 1 кОм (B1K):**
   * Левая ножка ➔ в шину **+5V**
   * Средняя ножка ➔ к красному проводу динамика
   * Правая ножка ➔ свободна
   *(Номинал 1 кОм обеспечивает идеальную плавность регулировки для динамика 8 Ом!)*

---

### Блок Д. Подключение OLED дисплея 0.96" I2C (SSD1306)
* **GND** ➔ в синюю шину **GND**
* **VCC** ➔ в красную шину **+5V**
* **SCL** ➔ в пин **`A5`** Arduino
* **SDA** ➔ в пин **`A4`** Arduino

---

## 3. Сводная таблица всех проводков на макетке

| Откуда (деталь / контакт) | Куда подключить | Назначение |
|---|---|---|
| Джек 3.5 мм: **Sleeve** | **GND** | Общий провод весла |
| Джек 3.5 мм: **Tip** | **D2** (+ 10 кОм к 5V) | Точки (DIT) |
| Джек 3.5 мм: **Ring** | **D3** (+ 10 кОм к 5V) | Тире (DAH) |
| Транзистор: **Эмиттер (E)** | **GND** | Земля ключа |
| Транзистор: **База (B)** | **D6** через 1 кОм | Управление звуком |
| Транзистор: **Коллектор (C)** | Черный провод динамика | Выход звука |
| Конденсатор **100 нФ** | Между Коллектором и GND | Фильтр частоты (бархатный тон) |
| Светодиод зеленый (PWR): **Анод** | **+5V** через 1 кОм (Катод на GND) | Индикатор питания |
| Светодиод красный (KEY): **Анод** | **D8** через 1 кОм (Катод на GND) | Индикатор передачи |
| POT 3 (Громкость, **1 кОм**): ползунок | Красный провод динамика | Питание динамика через реостат |
| POT 1 (WPM, **10 кОм**): ползунок | **A0** | Замер скорости |
| POT 2 (Тон, **10 кОм**): ползунок | **A2** | Замер частоты тона |
| OLED: **SDA** | **A4** | Данные экрана I2C |
| OLED: **SCL** | **A5** | Тактирование экрана I2C |
| Arduino **5V** и **GND** | Шины **+5V** и **GND** макетки | Главное питание |
