# CW Keyer Hardware (MorseWave Edition)

Набор документации, схем и прошивок для аппаратного телеграфного кейера MorseWave Keyer v1.0.

## Содержимое папки:

1. **`keyer_breadboard.ino`** — Основная боевая прошивка для Arduino Uno/Nano:
   - Аппаратный Iambic B с памятью точек/тире и режимом Squeeze
   - Спортивная раскладка СРТ (Точки = D2, Тире = D3)
   - Динамическая ручка скорости WPM (пин A0)
   - Динамическая ручка тона PITCH (пин A2)
   - Вывод на дисплей OLED 0.96" I2C (GyverOLED, без буфера)
   - Вывод звука на пин D6 + светодиод передачи на пине D8
   - Стрим символов в WebSerial (115200 бод) для MorseWave

2. **`test_hardware.ino`** — Минимальный проверочный скетч (без I2C/OLED):
   - Проверка нажатий весла, звука на D6 и светодиода на D8

3. **`breadboard-wiring.md`** — Подробная пошаговая карта соединений проводков на макетке (Breadboard)

4. **`cw-keyer-guide-full.md`** — Полный мануал: спецификация, BOM (список покупок), схемы стартовой и полной версии

5. **`cw-keyer-schematic.md`** — Принципиальная схема со всеми номиналами для будущей трассировки в KiCad/EasyEDA

6. **`circuit-simulator-full.html`** — Интерактивный симулятор всей системы (OLED, макросы, оптопары, звук) в браузере

7. **`circuit-simulator.html`** — Базовый интерактивный симулятор схемы
