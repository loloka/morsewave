### Схема стартовой версии:

```
                              Arduino Uno / Nano
                       ┌───────────────────────┐
                       │                   +5V ├─── [Шина питания +5V]
                       │                   GND ├─── [Шина земли GND]
                       │                       │
                       │                    D2 ├─── Точки (DIT)  [Указательный]
                       │                    D3 ├─── Тире (DAH)   [Большой палец]
                       │                    D6 ├─── Звук (PWM)
                       └───────────────────────┘

1. ВХОД ВЕСЛА (Гнездо 3.5 мм TRS):
   +5V ──── [Резистор 10 кОм] ────┬──── Arduino D2
                                  └──── TIP (Точки, указательный палец)

   +5V ──── [Резистор 10 кОм] ────┬──── Arduino D3
                                  └──── RING (Тире, большой палец)

   GND ──────────────────────────────── SLEEVE (Корпус разъема 3.5 мм)


2. ПРОКАЧАННЫЙ ЗВУКОВОЙ ТРАКТ (NPN Транзистор + Фильтр):

                      +5V
                       │
                 [Динамик 8 Ом]
                       │
       Arduino D6 ─────┼───► Коллектор (C)
            │          │
        [1 кОм]     [100 нФ]  ◄── Срезает колючие гармоники (мягкий синус)
            │          │
            └──────► База (B) 
                       │
                    Эмиттер (E) ──── GND
```

# Часть 2. ПОЛНАЯ ВЕРСИЯ (Автономный комбайн с экраном, памятью и ТРЕМЯ крутилками)

Цель: автономная работа без ПК, OLED-экран, **ручка скорости WPM (10к) + ручка тона PITCH (10к) + ручка громкости VOLUME (1к)**, светодиоды и выходы на трансивер.

### Полная спецификация потенциометров:
* **VR1 (Скорость WPM):** 10 кОм (B10K, линейный) ➔ пин `A0`
* **VR2 (Тон PITCH):** 10 кОм (B10K, линейный) ➔ пин `A2`
* **VR3 (Громкость VOLUME):** **1 кОм (B1K)** ➔ в цепь динамика (дает идеальную плавность)

---

### Полная схема соединений (Uno / Nano):

```
                   Arduino Uno / Nano
            ┌───────────────────────┐
            │                   +5V ├─── Шина питания +5V
            │                   GND ├─── Общая земля
            │                       │
    ВЕСЛО   │                    D2 ├─── TIP (Точки, указательный)  [+ 10k к 5V]
            │                    D3 ├─── RING (Тире, большой палец) [+ 10k к 5V]
            │                       │
  ТРАНСИВЕР │                    D4 ├─── [1 кОм] ──► PC817 #1 ──► Выход TX KEY
            │                    D5 ├─── [1 кОм] ──► PC817 #2 ──► Выход PTT
            │                       │
  УСИЛИТЕЛЬ │                    D6 ├─── [1 кОм] ──► База NPN ──► Динамик 8 Ом
   LED KEY  │                    D8 ├─── [1 кОм] ──► Красный светодиод ──► GND
            │                       │
  СКОРОСТЬ  │                    A0 ├─── Ползунок потенциометра VR1 (10 кОм: WPM 10–45)
   КНОПКИ   │                    A1 ├─── Делитель матрицы кнопок SW1-SW6
    ТОН CW  │                    A2 ├─── Ползунок потенциометра VR2 (10 кОм: PITCH 450–850 Гц)
            │                       │
 OLED I2C   │              A4 (SDA) ├─── SDA дисплея OLED SSD1306
            │              A5 (SCL) ├─── SCL дисплея OLED SSD1306
            └───────────────────────┘
```

# Часть 3. Программная часть (WebSerial + MorseWave)

1. **Скорость COM-порта:** 115200 бод.
2. **Протокол событий в браузер:**
   * `.` — передана точка (DIT)
   * `-` — передано тире (DAH)
   * `[буква]` — распознанная буква после межзнаковой паузы (3 точки)
   * ` ` (пробел) — межсловная пауза (7 точек)
   * `W:xx` — текущая скорость WPM при повороте крутилки
3. **Задержка:** ~1–2 мс (нулевая задержка).
