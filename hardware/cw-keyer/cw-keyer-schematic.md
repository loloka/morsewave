# CW Keyer v1.0 — Принципиальная схема
> Профессиональный электронный CW-кейер · **Arduino Nano / Uno (ATmega328P)**

---

## 1. Распределение пинов Arduino Nano / Uno

```
                        ┌─────────────────────────────┐
              RESET ────┤ RST            D13/SCK      ├──── (Встроенный LED)
               3.3V ────┤ 3V3            D12/MISO     ├──── (Резерв)
                 5V ────┤ 5V             D11/MOSI     ├──── (Резерв)
              GND  ─────┤ GND            D10          ├──── (Резерв)
              GND  ─────┤ GND            D9           ├──── (Резерв)
                        │                D8           ├──── KEY LED (красный, передача)
    SPEED POT (WPM) ────┤ A0             D7           ├──── (Резерв)
    BUTTON MUX (M1) ────┤ A1             D6 ♦         ├──── SIDETONE (PWM → База NPN транзистора)
    PITCH POT (Тон) ────┤ A2             D5 ♦         ├──── PTT OUT (через PC817)
                        ┤ A3             D4           ├──── TX KEY OUT (через PC817)
    OLED SDA        ────┤ A4 (SDA)       D3 ★         ├──── DAH paddle (INT1, большой палец)
    OLED SCL        ────┤ A5 (SCL)       D2 ★         ├──── DIT paddle (INT0, указательный палец)
                        │                D1/TX        ├──── USB Serial (WebSerial в MorseWave!)
                        │                D0/RX        ├──── USB Serial
                        └─────────────────────────────┘

  ★ = аппаратное прерывание (INT0/INT1) — критично для идеального тайминга ямбика
  ♦ = аппаратный PWM пин
```

## 2. Блок питания и фильтрации

```
  USB 5V (ПК / Повербанк) ──► Arduino 5V
                                 │
                 ┌───────────────┴───────────────┐
                 │                               │
              C1=100нФ                        C2=100нФ
                 │                               │
                GND                             GND
        (керамика у оптопар)            (керамика у дисплея)
```

## 3. Блок весла (Paddle Input — СРТ раскладка)

```
  3.5mm STEREO JACK (J1) — PADDLE IN
  ┌──────────────────┐
  │ TIP   = DIT (·)  ├──────────────────────────┐
  │ RING  = DAH (-)  ├───────────────┐           │
  │ SLEEVE= GND      ├──── GND       │           │
  └──────────────────┘               │           │
                                     │           │
  5V ──[R1=10kΩ]──┬── D3 (INT1)     │           │
                  │                 │           │
                [DAH] ──────────────┘           │
                                                │
  5V ──[R2=10kΩ]──┬── D2 (INT0)                │
                  │                             │
                [DIT] ──────────────────────────┘

  • D2 (указательный) = ТОЧКИ
  • D3 (большой палец) = ТИРЕ
  • Замыкание на землю (LOW) = нажатие
```

## 4. Блок TX KEY и PTT (Гальваническая развязка)

```
  TX KEY:
  Arduino D4 ──[R3=1kΩ]──► [A] PC817 #1 [K] ──── GND
                            [C]         [E]
                             │           │
                            J2 TIP      J2 GND (к трансиверу)

  PTT:
  Arduino D5 ──[R4=1kΩ]──► [A] PC817 #2 [K] ──── GND
                            [C]         [E]
                             │           │
                            J3 TIP      J3 GND (к трансиверу)
```

---

## 5. Блок звука (NPN усилитель + RC фильтр + Регулировка громкости)

```
                      +5V
                       │
                 [Динамик 8 Ом]
                       │
                       ├─────────────────────┐
                       │                     │
                  Коллектор (C)           C3=100нФ (керамика)
                       │                     │
  Arduino D6 ──[R5=1kΩ]─ База (B)            │
                       │                     │
                  Эмиттер (E) ───────────────┴──── GND

  • Транзистор: BC547 или 2N2222
  • C3 срезает паразитные гармоники меандра, давая мягкий тон.
  • Опция регулировки громкости: потенциометр 1 кОм последовательно с динамиком.
```

## 6. Блок регулировок (Аналоговые входы A0 и A2)

### 6.1. Регулировка скорости (WPM):
```
       +5V
        │
     ┌──┤ 1
     │  VR1 = 10 кОм (линейный B10K — СКОРОСТЬ 5–50 WPM)
     ├──┤ 2 (ползунок) ────────────── A0
     │  │
     └──┤ 3
        │
       GND
```

### 6.2. Регулировка тона звука (PITCH):
```
       +5V
        │
     ┌──┤ 1
     │  VR2 = 10 кОм (линейный B10K — ТОН 400–900 Гц)
     ├──┤ 2 (ползунок) ────────────── A2
     │  │
     └──┤ 3
        │
       GND
```

## 7. Блок кнопок памяти (Аналоговая резистивная лестница)

```
  Все 6 кнопок заведены на ОДИН аналоговый пин A1!

       +5V
        │
     [R6=10кΩ] (подтяжка)
        │
        ├─────────────────────────────── A1
        │
        ├──[прямо на GND]── SW1 (CMD) ── GND  → ~0V
        ├──[R7=1кΩ]─────── SW2 (M1)  ── GND  → ~0.45V
        ├──[R8=2.2кΩ]───── SW3 (M2)  ── GND  → ~0.90V
        ├──[R9=3.3кΩ]───── SW4 (M3)  ── GND  → ~1.24V
        ├──[R10=4.7кΩ]──── SW5 (M4)  ── GND  → ~1.60V
        └──[R11=6.8кΩ]──── SW6 (M5)  ── GND  → ~2.02V
```

## 8. Блок OLED дисплея (I2C)

```
  Arduino A4 (SDA) ──────────── OLED SDA
  Arduino A5 (SCL) ──────────── OLED SCL
  +5V              ──────────── OLED VCC
  GND              ──────────── OLED GND
```

---

## 9. Блок светодиодов (LEDs)

```
  PWR LED (зеленый):
  +5V ──[R12=1кΩ]──► Анод LED_GRN Катод ──── GND

  KEY LED (красный):
  Arduino D8 ──[R13=220Ω]──► Анод LED_RED Катод ──── GND
```
