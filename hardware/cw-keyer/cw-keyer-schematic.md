# CW Keyer v1.0 — Принципиальная схема
> Профессиональный электронный CW-кейер · **Arduino Nano / Uno (ATmega328P)**

---

## 1. Распределение пинов Arduino Nano / Uno

```
                        ┌─────────────────────────────┐
              RESET ────┤ RST            D13/SCK      ├──── (Встроенный LED)
               3.3V ────┤ 3V3            D12/MISO     ├──── (Резерв)
                 5V ────┤ 5V             D11/MOSI     ├──── (Резерв)
              GND  ─────┤ GND            D10          ├──── (Резерв)
              GND  ─────┤ GND            D9           ├──── (Резерв)
                        │                D8           ├──── KEY LED (красный, передача)
    SPEED POT (WPM) ────┤ A0             D7           ├──── (Резерв)
    BUTTON MUX (M1) ────┤ A1             D6 ♦         ├──── SIDETONE (PWM → База NPN транзистора)
    PITCH POT (Тон) ────┤ A2             D5 ♦         ├──── PTT OUT (через PC817)
                        ┤ A3             D4           ├──── TX KEY OUT (через PC817)
    OLED SDA        ────┤ A4 (SDA)       D3 ★         ├──── DAH paddle (INT1, большой палец)
    OLED SCL        ────┤ A5 (SCL)       D2 ★         ├──── DIT paddle (INT0, указательный палец)
                        │                D1/TX        ├──── USB Serial (WebSerial в MorseWave!)
                        │                D0/RX        ├──── USB Serial
                        └─────────────────────────────┘

  ★ = аппаратное прерывание (INT0/INT1) — критично для идеального тайминга ямбика
  ♦ = аппаратный PWM пин
```

## 3. Блок весла (Paddle Input — СРТ раскладка)

```
  3.5mm STEREO JACK (J1) — PADDLE IN
  ┌──────────────────┐
  │ TIP   = DIT (·)  ├──────────────────────────┐
  │ RING  = DAH (-)  ├───────────────┐           │
  │ SLEEVE= GND      ├──── GND       │           │
  └──────────────────┘               │           │
                                     │           │
  5V ──[R1=10kΩ]──┬── D3 (INT1)     │           │
                  │                 │           │
                [DAH] ──────────────┘           │
                                                │
  5V ──[R2=10kΩ]──┬── D2 (INT0)                │
                  │                             │
                [DIT] ──────────────────────────┘

  • D2 (указательный) = ТОЧКИ
  • D3 (большой палец) = ТИРЕ
  • Замыкание на землю (LOW) = нажатие
```

```
  TX KEY:

                            [C]         [E]
                             │           │

                            [C]         [E]
                             │           │
                            J3 TIP      J3 GND (к трансиверу)
```

## 5. Блок звука (Улучшенный аналоговый тракт: 2-звенный ФНЧ + Регулятор громкости + BC547)

Профессиональный звуковой тракт преобразует резкий цифровой прямоугольный ШИМ (вывод D6, частота 400–1200 Гц) в мягкий, бархатный аналоговый тон (псевдосинус). Звук не утомляет слух и не вызывает головной боли даже при многочасовых тренировках в наушниках.

```
  Arduino D6 (PWM)
       │
     [R_f1 = 1 кОм]
       │
       ├──────────────────────┐
       │                      │
   [C3 = 100 нФ]          [R_f2 = 1 кОм]
       │                      │
      GND                     ├──────────────────────────┐
                              │                          │
                         [C4 = 47 нФ]                ┌───┤ 1 (Вход с фильтра)
                              │                      │   │
                             GND                     │  [VR3 = 10 кОм] (ГРОМКОСТЬ / VOLUME)
                                                     │   │
                                                     │   ├── 2 (Движок) ──[R_base = 470 Ом]──► База (B) Q1 BC547
                                                     │   │                                              │
                                                     └───┤ 3 (GND) ──── GND                             │
                                                                                                        │
                      +5V                                                                       Эмиттер (E) ── GND
                       │                                                                                │
                 [R_bal = 33 Ом, 1 Вт] (балласт защиты динамика)                                        │
                       │                                                                                │
                 [Динамик 8 Ом 1.5 Вт]                                                                  │
                       │                                                                                │
                       ├─────────────────────── Коллектор (C) ◄─────────────────────────────────────────┘
                       │
                       ├──────[C5 = 100 нФ]────── GND (демпфер индуктивных выбросов)
                       │
                       └──────[R_ph = 150 Ом]───► Выход наушников (J7 PHONES Jack 3.5 мм)
```

### Как устроен этот узел:
* **2-звенный фильтр Баттерворта ($R_{f1} C_3$ и $R_{f2} C_4$):** спад АЧХ 40 дБ/декада. Полностью срезает высокочастотные гармоники выше 1.5 кГц, убирая «металлическое дребезжание» меандра.
* **Подключение регулятора громкости VR3 (задействованы все 3 ножки):**
  * **Ножка 1:** сигнал с выхода ФНЧ;
  * **Ножка 3:** общая земля GND;
  * **Ножка 2 (средняя):** регулируемый съем уровня на базу транзистора через $R_{base}$ (470 Ом).
  * *Почему именно 3 ножки:* это полноценный **потенциометрический делитель напряжения**. В крайнем левом положении движок садится на GND — получается идеальная тишина (Mute). В правом положении — 100% громкости. Регулировка плавная по всей шкале 270°.
* **Балластный резистор $R_{bal}$ (33 Ом, 1 Вт):** ограничивает постоянный ток через обмотку динамика 8 Ом, предотвращая её перегрев и перегрузку транзистора.
* **Выход для наушников PHONES:** через защитный резистор 150 Ом звук звучит комфортно и чисто в любых наушниках без щелчков.

## 6. Блок регулировок (Аналоговые входы A0 и A2)

### 6.1. Регулировка скорости (WPM):
```
       +5V
        │
     ┌──┤ 1
     │  VR1 = 10 кОм (линейный B10K — СКОРОСТЬ 5–50 WPM)
     ├──┤ 2 (ползунок) ────────────── A0
     │  │
     └──┤ 3
        │
       GND
```

### 6.2. Регулировка тона звука (PITCH):
```
       +5V
        │
     ┌──┤ 1
     │  VR2 = 10 кОм (линейный B10K — ТОН 400–900 Гц)
     ├──┤ 2 (ползунок) ────────────── A2
     │  │
     └──┤ 3
        │
       GND
```

## 7. Блок кнопок памяти (Аналоговая резистивная лестница)

```
  Все 6 кнопок заведены на ОДИН аналоговый пин A1!

       +5V
        │
     [R6=10кΩ] (подтяжка)
        │
        ├─────────────────────────────── A1
        │
        ├──[прямо на GND]── SW1 (CMD) ── GND  → ~0V
        ├──[R7=1кΩ]─────── SW2 (M1)  ── GND  → ~0.45V
        ├──[R8=2.2кΩ]───── SW3 (M2)  ── GND  → ~0.90V
        ├──[R9=3.3кΩ]───── SW4 (M3)  ── GND  → ~1.24V
        ├──[R10=4.7кΩ]──── SW5 (M4)  ── GND  → ~1.60V
        └──[R11=6.8кΩ]──── SW6 (M5)  ── GND  → ~2.02V
```

## 8. Блок OLED дисплея (I2C)

```
  Arduino A4 (SDA) ──────────── OLED SDA
  Arduino A5 (SCL) ──────────── OLED SCL
  +5V              ──────────── OLED VCC
  GND              ──────────── OLED GND
```

## 9. Блок светодиодов (LEDs)

```
  PWR LED (зеленый):
  +5V ──[R12=1кΩ]──► Анод LED_GRN Катод ──── GND

  KEY LED (красный):
  Arduino D8 ──[R13=220Ω]──► Анод LED_RED Катод ──── GND
```
